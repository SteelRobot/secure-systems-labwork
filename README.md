# Система приёма и обработки заявок на материальную поддержку (ЛР №3)

Университетская цифровая система для автоматизации подачи, проверки и обработки заявок студентов и сотрудников на материальную поддержку и ПГАС.

---

## 1. Требования к компьютеру
- **ОС:** Linux / macOS / Windows (с подсистемой WSL2).
- **Программное обеспечение:** `Docker` (20.10+), `Docker Compose` (v2+), `bash`, `curl`.
- **Свободные порты:**
  - `8443` (HTTPS веб-клиент)
  - `8080` (HTTP редирект веб-клиента)
  - `8025` (Mailpit почтовый сервер)
  - `15672` (RabbitMQ консоль)
  - `9001` (MinIO/S3 веб-консоль хранилища)

---

## 2. Быстрый запуск (за 1 минуту)

1. **Генерация переменных окружения и секретов:**
   ```bash
   ./scripts/init-env.sh
   ```
   *Скрипт создаст `.env` на основе `.env.example` со случайными паролями БД, Redis, RabbitMQ, MinIO, перцем и ключом подписи JWT.*

2. **Запуск всей системы одной командой:**
   ```bash
   docker compose up -d --build
   ```

3. **Остановка системы:**
   ```bash
   docker compose down
   ```

4. **Сброс базы и хранилища в исходное состояние:**
   ```bash
   docker compose down -v && docker compose up -d --build
   ```

## 3. Адреса и порты сервисов

| Сервис | Протокол / Порт | Адрес | Описание |
|---|---|---|---|
| **Веб-клиент** | HTTPS / `8443` | https://localhost:8443 | Главный пользовательский интерфейс |
| **Backend API** | HTTPS / `8443` | https://localhost:8443/api | REST API приложение (FastAPI) |
| **Mailpit (Почта)** | HTTP / `8025` | http://localhost:8025 | Почтовый сервер для просмотра писем с кодами сброса пароля |
| **RabbitMQ** | HTTP / `15672` | http://localhost:15672 | Консоль брокера сообщений (логин/пароль из `.env`) |

## 5. Проверка работы (Коллекция скриптов в `requests/`)

В папке `requests/` расположены скрипты для автоматической проверки функционала:
- `./requests/check_1_other_user_object.sh` — проверка защиты чужих объектов (Задание 7.2.1).
- `./requests/check_2_extra_fields.sh` — проверка защиты от внедрения лишних полей в тело запроса (Задание 7.2.2).
- `./requests/check_3_privileged_operation.sh` — проверка запрета вызова админ-операций обычным пользователем (Задание 7.2.3).
- `./requests/auth.sh`, `./requests/auth_advanced.sh` — проверка входа, регистрации, выхода и сброса пароля через Mailpit.
- `./requests/applications.sh`, `./requests/applications_list.sh` — проверка создания, просмотра и фильтрации заявок.
- `./requests/documents.sh` — проверка загрузки и скачивания подтверждающих документов.
- `./requests/submit.sh`, `./requests/status.sh` — проверка переходов состояний заявки.
- `./requests/llm_check.sh` — проверка асинхронного вызова ИИ-анализа заявки.
- `./requests/reports.sh` — проверка генерации сводных отчётов.

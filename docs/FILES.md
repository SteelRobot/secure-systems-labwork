# Назначение файлов приложения

## Корень

| Файл | Назначение |
|---|---|
| `docker-compose.yml` | Описывает все контейнеры (db, redis, broker, storage, mail, external-stubs, api, worker, web и одноразовые db-seed, storage-init), две сети (`front`: web↔api, `data`: всё остальное), тома и порядок запуска. Секреты берёт из `.env`. |
| `.env.example` | Список всех переменных окружения с комментариями, без значений. Шаблон для `.env`. |
| `.env` | Реальные секреты. Создаётся скриптом, в git не попадает (в `.gitignore`). |
| `.gitignore` | Исключает `.env`, служебные файлы Emacs/LaTeX, `__pycache__`, `node_modules`, `web/dist`. |
| `README.md` | Требования к ПК, запуск и остановка, адреса сервисов, тестовые учётные записи, сброс базы. |
| `scripts/init-env.sh` | Генерирует `.env` из `.env.example` со случайными паролями, ключом JWT и перцем. Существующий `.env` не перезаписывает. |

## `db/` — база данных

| Файл | Назначение |
|---|---|
| `schema.sql` | Схема из ЛР №2 (с удалёнными платёжными полями и добавлен статус `needs_revision`). Postgres выполняет её при первом запуске на пустом томе. |
| `roles.sql` | Создаёт роли `app_api` и `app_worker` и выдаёт им минимальные права через GRANT. DDL им запрещён. |
| `init-roles.sh` | Обёртка: передаёт пароли ролей из окружения в `roles.sql` как переменные psql. Запускается при инициализации БД. |

## `api/` — основной сервис (FastAPI)

| Файл | Назначение |
|---|---|
| `Dockerfile` | Образ на Python 3.12, запуск от непривилегированного пользователя. |
| `requirements.txt` | Зависимости: FastAPI, psycopg, redis, pika, minio, argon2-cffi, pyjwt, email-validator. |
| `app/main.py` | Точка входа FastAPI, обработчик глобальных ошибок (500 без деталей), регистрация роутеров. |
| `app/config.py` | Конфигурация из переменных окружения. |
| `app/db.py` | Пул соединений PostgreSQL под ролью `app_api`. |
| `app/cache.py` | Клиент Redis для сессий, лимитов частоты и кодов сброса паролей. |
| `app/broker.py` | Отправка сообщений в RabbitMQ. |
| `app/storage.py` | Клиент S3 API (RustFS). |
| `app/deps.py` | Зависимость аутентификации `get_current_user` (валидация JWT и сессии в Redis). |
| `app/security.py` | Хеширование паролей Argon2id + перец. |
| `app/seed.py` | Начальное заполнение БД тестовыми пользователями и заявками. |
| `app/storage_init.py` | Одноразовое создание бакета `documents` в S3. |
| `app/routers/auth.py` | Вход, регистрация, выход, сброс и подтверждение пароля. |
| `app/routers/applications.py` | Создание, отправка, просмотр, список, загрузка/скачивание документов, смена статуса и ИИ-проверка. |
| `app/routers/reports.py` | Генерация и скачивание сводных отчётов подразделений. |

## `worker/` — фоновый обработчик

| Файл | Назначение |
|---|---|
| `Dockerfile` | Образ на Python 3.12. |
| `requirements.txt` | Зависимости воркера. |
| `worker/main.py` | Слушает очереди RabbitMQ (`audit`, `notifications`, `reports`): пишет аудит в БД, отправляет письма в Mailpit, генерирует CSV-отчёты в S3 и уведомляет финансы. |

## `web/` — клиент (React + nginx)

| Файл | Назначение |
|---|---|
| `Dockerfile` | Сборка SPA и запуск nginx с HTTPS сертификатом. |
| `nginx.conf` | Конфигурация nginx с редиректом на HTTPS, заголовками безопасности и проксированием `/api/`. |
| `src/App.tsx` | Пользовательский интерфейс: формы входа, регистрации, восстановления пароля, подачи заявок, прикрепления и просмотра документов, смены статусов и генерации отчётов. |

## `rabbitmq/` — брокер

| Файл | Назначение |
|---|---|
| `definitions.template.json` | Шаблон очередей, обменников и прав пользователя `app`. |
| `rabbitmq.conf` | Конфигурация RabbitMQ. |
| `entrypoint.sh` | Подставляет пароли из `.env` в `definitions.template.json` и запускает брокер. |

## `external-stubs/` — заглушки внешних систем

| Файл | Назначение |
|---|---|
| `main.py` | Заглушка финансового подразделения (`POST /finance/reports`) и системы мониторинга (`POST /metrics`). |

## `requests/` — проверочные скрипты

| Файл | Назначение |
|---|---|
| `check_1_other_user_object.sh` | Проверка 7.2.1: забор чужого объекта под действительным токеном. |
| `check_2_extra_fields.sh` | Проверка 7.2.2: создание объекта с внедрёнными лишними полями. |
| `check_3_privileged_operation.sh` | Проверка 7.2.3: вызов админ-операции токеном обычного пользователя. |
| `auth.sh`, `auth_advanced.sh` | Тесты аутентификации, регистрации, выхода и восстановления доступа. |
| `applications.sh`, `applications_list.sh` | Тесты создания, чтения и фильтрации заявок. |
| `documents.sh` | Тест прикрепления и просмотра документов. |
| `submit.sh`, `status.sh` | Тесты смены состояний и отправки заявок. |
| `llm_check.sh` | Тест ИИ-проверки полноты обращения. |
| `reports.sh` | Тест генерации и скачивания отчётов. |
